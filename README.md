# Caminho do Bem

Landing do **Projeto Social Caminho do Bem** — OSC de Canoas e Bagé (RS).

## Paleta

- Fundo branco
- Roxo `#5B2D91` (caminho, títulos, botões)
- Amarelo `#F5C518` (destaques e convites)

## Como rodar

```bash
npm install
npm run dev
```

O servidor sobe em `http://127.0.0.1:4327`.

```bash
npm run build
npm run preview
```

## Stack

Astro 7, React 19, Tailwind CSS 4.
